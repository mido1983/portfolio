# Project instructions

## Privacy and public attribution

- Never publish, expose, index, or embed the owner's legal name or personal identity in source code, rendered UI, metadata, structured data, documentation, fixtures, screenshots, downloadable files, commit messages, or release notes.
- Use the public alias `MiDo` or the project brand when attribution is required.
- Treat this as a release-blocking requirement. An exception requires explicit, case-specific approval from the owner.
